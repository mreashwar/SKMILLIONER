FIX FOR GITHUB PAGES / NETLIFY
1. Extract this ZIP on your computer.
2. Open the extracted folder and confirm that index.html AND the assets folder are together.
3. Upload the CONTENTS of this folder to the ROOT of your GitHub repository (not just the HTML files). The repository root should show index.html and an assets folder side by side.
4. Commit changes and wait for GitHub Pages to redeploy.
5. Hard refresh the website (Ctrl+F5) or open it in a private/incognito tab.

If uploading to Netlify, drag the extracted folder itself into the manual deploy area.

ENQUIRY FORM
The contact form prepares an email using the visitor's email app. It does not store enquiries on a server. To receive submissions without opening an email app, connect Netlify Forms or Formspree.
