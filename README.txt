SATHISH KUMAR — DIGITAL PRODUCT STUDIO PORTFOLIO

PAGES
- index.html: home / overview
- work.html: concept studies (clearly labelled as concepts)
- services.html: service menu and process
- about.html: about / working principles
- contact.html: project enquiry form

RUN LOCALLY
Open index.html in a modern browser. The site uses plain HTML, CSS and JavaScript; no build step or paid library is required. Google Fonts are optional and require an internet connection; fallback fonts are included.

FREE HOSTING
Netlify: drag the extracted sathish-studio folder into the Netlify deploy page.
GitHub Pages: upload the folder contents to a repository and enable Pages in repository settings.

ENQUIRY FLOW
The contact form validates required fields and opens the visitor's email application with a pre-filled message to sathishkumarda1999@gmail.com. This is a static-site mailto workflow; it does not store enquiries in a database or send them silently. To receive enquiries without the visitor opening an email app, connect a form provider (for example Netlify Forms or FormSubmit) after deployment.

PERSONALISATION
The portrait-concept.png image is an AI-generated editorial concept portrait, not a verified likeness. Replace it with your approved real portrait if desired. The portfolio projects are concept studies, not real client case studies. Update project details, testimonials, metrics and availability only with verified information.
